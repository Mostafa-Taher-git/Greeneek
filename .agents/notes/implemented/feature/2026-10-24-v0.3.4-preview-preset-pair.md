# Agent Note: Preview presets mount the Craft gateway as role compositions

Status: implemented

## Problem

The [Craft bridge pilot](2026-10-24-v0.3.4-craft-bridge-pilot.md) shipped the gateway seam with no session surface mounting it, and the v0.3.4 plan (workstreams D+E) calls for two role agents that reach installed creative apps through it: a design brief worker and a teaching agent that drafts lessons, tutorials, and CVs. The default `standard` composition grants shell tools and the full coding catalog, which neither role needs, and the pilot's `unverified` manifests must not reach that default. The hero mode switcher also had no vocabulary for a shipped-but-partial surface: every visible mode was a finished promise.

## Decision

`gnk-agent-presets` ships two additional built-in compositions, `presets/pixels-designer/` (roster order 3) and `presets/instructor/` (roster order 5), each an independent assembly rather than an edit of `standard`:

- **Craft gateway inside the preset realm.** Both mount `@greeneek/gnk-craft` (service, `maxActiveApps: 2`), `@greeneek/gnk-craft-local`, and `@greeneek/gnk-tool-craft` in one `cordis:group` with `isolate: {craft: true}`, so gateway state and the two model-facing tools belong to sessions on these presets alone.
- **Trimmed capability floor.** Both carry persona, agent-instructions, `tool-fs`, `tool-fs-search`, `tool-ask-user`, `tool-todo`, and `tool-web` with fetch enabled. Pixels Designer adds the planning group; Instructor omits it. Neither mounts shell tools, so the shell-gating test keeps its explicit `standard`/`ptc`/`cordis` roster.
- **Personas constrain honesty.** Pixels Designer interviews via `ask_user_question` before drafting. Instructor carries an anti-fabrication rule (every user-facing fact traces to user input or a cited fetch; missing facts become questions or explicit placeholders), a CV flagship flow whose critical path is markdown drafted in the workspace and exported through PdfCraft headless, and a failure contract: when an app is absent or an export fails, deliver the markdown and say so — never claim an app ran.
- **Preview naming is uniform.** `(preview)` / `（预览）` appears in each `preset.yml` name, both locale dictionaries, and the `MODE_ORDER` row copy, so a pilot surface is never mistaken for a promise; `display.ts` keys complete the fold between file copy and localized copy.
- **Row placement.** The hero switcher follows `MODE_ORDER` (`standard`, `pixels-designer`, `instructor`, `cordis`) with new lucide-derived 16px icons (palette, graduation-cap); the Settings built-in section sorts by the `preset.yml` `order` field. `apps/cli/package.json` declares the three craft packages so the preset rows resolve above the harness base.

## Alternatives considered

**One shared "craft" preset for both roles.** Rejected: the two personas enforce different obligations (interview-then-design versus anti-fabrication-then-export) and different tool floors (planning on, planning off); one file would average both roles into neither.

**Duplicate `standard`'s assembly and add the gateway, as `cordis` and `ptc` do.** Rejected: both preview agents would inherit shell tools and the coding catalog the roles never use, and the shell grant contradicts the pilot's confined-roots posture.

**Mount the gateway into `standard`.** Rejected for the same reason the [pilot note](2026-10-24-v0.3.4-craft-bridge-pilot.md) rejected it: `unverified` manifests stay off the default composition; the preview presets are where pilot exposure lands.

**Hide the new rows behind a settings flag.** Rejected: `HIDDEN_FROM_ROW` exists for the retired `ptc` pill; a preview the user can select is more honest than a feature flag nobody finds, and the `(preview)` suffix already carries the caveat.

## Consequences

- The built-in roster is five presets, and every preset-enumerating surface moved with it: shipped-root health fetches, the web e2e roster assertions, the locales parity table, and the four `apps/web` aria goldens. The hero golden was stale since the [PTC pill removal](../simplification/2026-10-24-ptc-pill-removal.md) and the keyless lanes never caught it; it was corrected in this same wave, so the goldens now match shipped rows.
- Sessions on other presets pay nothing: no craft child, no gateway schemas, no realm.
- A user can select a preview preset whose gateway reports no installed apps; the persona's honesty contract is the mitigation until the Windows real-app E2E flips manifest `verified` flags.
- Copy edits must keep three sources in sync per preset: `preset.yml` (zh fallback), `locales.ts` (en+zh dictionaries), and `display.ts` keys — the same discipline `standard` and `ptc` already follow.
